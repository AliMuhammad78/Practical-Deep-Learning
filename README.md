# 📌 About The Repository

This repository contains beginner-friendly and practical Deep Learning notebooks covering neural networks, model training, evaluation, and optimization techniques using TensorFlow and Keras.

The notebooks are designed to help students and developers understand Deep Learning concepts through hands-on implementation and experimentation.

## 🧠 Neural Networks

* Forward & Backpropagation
* Activation Functions
* Loss Functions

## 🖼 Computer Vision

## ⚡ Optimization
